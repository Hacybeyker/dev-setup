# Plugins de Claude Code que instala dev-setup (scope user) y actualiza `dev-setup update`.
# Formato: <plugin>@<marketplace> [grupo]. Con grupo, solo se instala si ese grupo opcional está activo.
# Cada marketplace va en marketplaces.txt.

# Diagnósticos y navegación de código Kotlin (servidor de JetBrains). En alpha: Android experimental, KMP aún sin soporte.
kotlin-lsp@claude-plugins-official
# Documentación actualizada de librerías por versión (MCP de Upstash).
context7@claude-plugins-official
# Agentes de review especializados: segunda pasada después de hb-review.
pr-review-toolkit@claude-plugins-official
# Avisos de seguridad al editar y revisión del diff al final de cada turno (consume tokens).
security-guidance@claude-plugins-official
# Auditar y mejorar CLAUDE.md y AGENTS.md.
claude-md-management@claude-plugins-official
# Flujo genérico de features para proyectos sin AGENTS.md.
feature-dev@claude-plugins-official
# Notificaciones de Warp cuando Claude Code necesita input. Solo con el grupo terminal.
warp@claude-code-warp terminal
